# PCBridge

云端智能体的"手"——让云端 AI（带着全部上下文的"大脑"）操作你的 Windows 电脑，
而本机只装一个零依赖的 PowerShell 小脚本（"手"），没有任何本地智能。

灵感来自一个真实痛点：AI 在服务器上把代码改好了，用户还要手动下载、拖进 IDE、
编译，来回传十趟文件。PCBridge 把这个闭环变成"云端下发任务 → 你点一下允许"。

## 能干什么

三种任务，覆盖"送文件 + 干活 + 取结果"全流程：

| 任务 | 说明 |
|------|------|
| `run` | 在你电脑上跑命令（如 `gradlew assembleDebug`） |
| `put` | 服务器 → 你电脑 送文件 |
| `get` | 你电脑 → 服务器 取文件 |

## 设计要点

- **云端是大脑，本机是手**：手只执行，不带任何上下文；任务由云端编排。
- **手主动拨号**：手从你电脑向外连服务器（长轮询），不需要公网 IP、不需要端口映射。
- **10 秒安装**：下载一个 .ps1，运行，输入 6 位配对码，完事。
- **三档权限**：
  - 自动放行（只读类）
  - 弹框询问（默认，可"这类以后都允许"）
  - 直接禁止（删除、改注册表、关机等——连"允许"按钮都没有）
- **全部留痕**：每个任务（含被拒绝的）永久存档，网页控制台可回放。
- **安全基线**：
  - 服务器只存设备令牌的 SHA-256，泄露数据库也拿不到可用令牌；
  - 配对码一次性 + 10 分钟过期 + 连错 3 次锁 10 分钟；
  - 管理口令/令牌存 600 权限文件，不进命令行、不进日志；
  - API 的管理端点在口令不对时装 404（不存在）。

## 组件

```
app/            Flask 服务端（设备配对、任务派发、长轮询、文件中转、网页控制台）
app/templates/  控制台页面（登录 / 设备列表 / 任务回放）
hand.ps1        Windows 端"手"（单文件，PowerShell 5.1 兼容，零安装）
tests/          冒烟测试、出配对码、派任务、清测试数据的小工具
DESIGN.md       设计文档
```

## 部署

```bash
# 1. 生成管理令牌（写入 pcbridge.env，600 权限，不回显）
python3 bootstrap-token.py

# 2. 构建并启动（默认监听 127.0.0.1:8003）
docker compose up -d --build

# 3. 冒烟测试
python3 tests/smoke_test.py
```

反向代理（nginx）要点：

- `/pb/` 前缀反代到 127.0.0.1:8003（去掉前缀）；
- `location = /dl/pcbridge-hand.ps1` 单文件免 basic auth（手的下载口）；
- 机器通道 `auth_basic off`（手有自己的令牌认证，弹不了浏览器登录框）。

更换管理令牌：`set-admin.sh`（交互式隐藏输入）。

## 使用

1. 把 `hand.ps1` 发到 Windows 电脑（或放在 web 目录下载），改好里面的
   `$ServerUrl` 默认值（`https://YOUR-SERVER-IP:8443/pb`）；
2. PowerShell 运行：

   ```powershell
   powershell -ep bypass -f "$env:USERPROFILE\Downloads\hand.ps1"
   ```

3. 打开控制台 `https://YOUR-SERVER-IP:8443/pb/console/`，点【添加电脑】
   拿配对码，输进"手"的窗口，完成。

任务派发走管理 API（`tests/send_task.py` 有现成例子），控制台负责查看
设备 / 回放任务 / 吊销设备。

## 已知的线路问题与对策

部署在按 TLS 握手域名（SNI）掐连接的线路上时，写域名的 HTTPS 请求会被
中间设备伪造 RST 掐掉（浏览器可能因握手包分段而幸免）。对策：手默认走
IP 直连（握手不带域名），证书校验改为"验链条 + 容忍域名不匹配"，安全等级
不降。排查方法（tcpdump 时间戳鉴别伪造 RST）见提交历史。
